🌞 Daily Greeting Project
A simple JavaScript project that displays a personalized greeting, the current time, and changes background images based on the user’s local time of day.

This project greets users based on their local time of day.
It displays a personalized message ("Good Morning", "Good Afternoon", "Good Evening"), shows the current time, and changes the background image accordingly.

🚀 Features

Dynamic greeting message depending on the time
Displays user’s local time
Background image and style update for morning, afternoon, and evening
Responsive and simple design
🛠️ Technologies Used

HTML for structure
CSS for styling
JavaScript for time detection and DOM updates
🎯 What I Learned

How to use the Date() object in JavaScript
Getting the current hour with .getHours()
Conditional statements (if / else if / else)
Changing content dynamically with innerText and src

💡 Future Improvements
Add user name input to greet by name
Show the current date (day/month/year)
